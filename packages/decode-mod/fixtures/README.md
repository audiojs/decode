# fixtures

`test.mod`, `test.xm`, `test.s3m`, `test.mptm` are libopenmpt's own loader regression
fixtures, copied verbatim from `lib/openmpt/test/` (libopenmpt-0.8.9). BSD-3-Clause,
same license as the rest of the [OpenMPT](https://github.com/OpenMPT/openmpt) repository.

No `test.it` ships in this libopenmpt release tag — `test.mptm` exercises the same
loader (`Load_it.cpp`), since MPTM is IT's OpenMPT-extended superset.
